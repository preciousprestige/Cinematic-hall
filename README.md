# Hall of Zero Limits - Immersive Cinematic UI

An immersive, cinematic web experience inspired by the Wakanda Forever Hall of Zero Limits, built with React and Framer Motion.

## 🚀 Features

- **Full-screen immersive sections** with smooth transitions
- **Wakanda-inspired aesthetic** with green holographic UI elements
- **7 unique section types**: Hero, Quote, Character Cards, Gallery, and Final
- **Smooth animations** powered by Framer Motion
- **Responsive design** that works across all devices
- **Section-based navigation** with PREV/NEXT controls
- **CSS clip-path** for signature hexagonal and angled borders

## 🛠️ Tech Stack

- **React 18** - UI framework
- **Vite** - Build tool and dev server
- **Framer Motion** - Animation library
- **CSS3** - Custom styling with clip-path, gradients, and animations

## 🎨 Design Decisions

### Architecture
- **Section-based navigation** instead of continuous scroll for better control and immersive transitions
- **Component-driven structure** with reusable section types
- **AnimatePresence** for smooth fade transitions between sections

### Styling
- **Green holographic theme** (#00ff41) matching Wakanda aesthetic
- **CSS clip-path polygons** for angled, futuristic borders
- **Layered backgrounds** with image + gradient overlay for depth
- **Responsive breakpoints** for mobile optimization

### Performance
- **Optimized images** from Unsplash CDN
- **Minimal dependencies** (only Framer Motion beyond React)
- **Efficient re-renders** with proper React state management
